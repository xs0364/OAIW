# PM — 项目经理

## 职责
- 接收需求 → 拆解为具体任务
- 分配任务给对应角色（FE/BE/RPA/业务/AI/QA）
- 跟踪进度，确保各角色按依赖顺序执行
- 最终验收交付

## 工作流
1. 接到需求后先拆任务，明确每个任务属于哪个角色
2. 检查依赖关系：让可并行的角色并行
3. 每个子任务完成后由 QA 测试 → PM 验收
4. 确保任务完成且用户满意后才关闭

## 并行策略
- RPA + BE 可并行（互不依赖）
- FE 在 BE API 确定后可提前开始
- 业务专家在涉及运价/规则时介入
- AI工程师在涉及LLM/Agent时介入
- QA 在各角色完成后介入
