# 任务 001 — BE: 合并「并行」和「一呼百应」为「多专家会诊」

## 背景
侧边栏AI助手的「并行」和「一呼百应」两个模式底层都是调用所有Agent，本质重复。
现合并为一个功能「🧠 多专家会诊」，提供「合成」和「对比」两种显示方式。

## 涉及文件
- `backend/addons/llm/multi_agent.py`
- `backend/addons/llm/routers/chat.py`

## 改动要求

### 1. multi_agent.py — 合并 chat_all() + chat_collaborate()

**新增方法** `chat_expert_panel()`，替代原来的 `chat_all()` 和 `chat_collaborate()`：

```python
async def chat_expert_panel(
    self,
    messages: list[dict],
    user_message: str = "",
    mode: str = "synthesize",  # "synthesize" | "compare"
    temperature: float = 0.7,
) -> dict:
```

**逻辑：**
- 始终使用各Agent的专业System Prompt（即原来 `AGENT_SYSTEM_PROMPTS` 的差异化角色设定）
- 始终并行调用所有Agent（各专业视角）
- `mode="synthesize"`（默认）：保持当前 `chat_collaborate()` 的合成逻辑，返回 `{synthesized, synthesizer, contributions}`
- `mode="compare"`：不合成，直接返回各Agent原始回答，格式同 `chat_all()` 但用专业提示词

**返回格式统一为：**
```python
{
    "success": True,
    "mode": "synthesize" | "compare",
    "synthesized": str,          # synthesize模式下有值
    "synthesizer": str,          # synthesize模式下有值
    "contributions": {           # 两种模式都有
        "nim_minimax": {"agent": "MiniMax M2.7", "content": "...", "model": "..."},
        ...
    }
}
```

**保留原有方法（暂时）**：`chat_all()` 和 `chat_collaborate()` 先不动，前端切完后统一清理。

### 2. chat.py — 合并API路由

class ExpertPanelRequest(BaseModel):
