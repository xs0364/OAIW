# 任务 001 — FE: 合并「并行」和「一呼百应」为「多专家会诊」

## 背景
侧边栏AI助手的「并行」和「一呼百应」两个模式底层逻辑重复，合并为一个「🧠 多专家会诊」，用户可在「合成模式」和「对比模式」之间切换。

## 涉及文件
- `frontend/src/views/AgentChat.vue`

## 改动要求

### 1. 下拉选项调整（第10-15行）

**原来：**
```
🤖 自动路由 (推荐)
⚡ GPT-OSS / Qwen / MiniMax / DeepSeek (各单项)
🔀 并行 (4个)
🔥 一呼百应 (协作模式)
```

**改为：**
```
🤖 自动路由 (推荐)
⚡ GPT-OSS / Qwen / MiniMax / DeepSeek (各单项)
🧠 多专家会诊
```

### 2. 选中「多专家会诊」时，显示模式切换开关

在聊天输入区上方或header区域，加一个切换组件：

```
🧠 多专家会诊  [○ 合成模式  ● 对比模式]
```

- **合成模式**（默认）：对应后端 `mode="synthesize"`，显示合成后的统一回答
- **对比模式**：对应后端 `mode="compare"`，显示各Agent独立回答卡片（类似现在的并行模式，但提示词更专业）

### 3. API调用变更

- 新增一个 `expertPanelMode` ref：`'synthesize' | 'compare'`
- 当 `agentMode === 'expert-panel'` 时，调用新端点：

```javascript
const res = await client.post('/chat/multi-agent/expert-panel', {
    message: userMsg,
    history: [],
    mode: expertPanelMode.value,
})
```

### 4. 展示逻辑

#### 合成模式（synthesize）
复用现在的 `collaborate-section` 样式：
- 显示「📋 综合AI分析」合成回答
- 可展开查看各Agent原始分析（`showRawContributions`）

#### 对比模式（compare）
复用现在的 `parallel-section` 卡片样式：
- 各Agent卡片并列展示
- 但label用专业角色名（如「🧠 深度分析」、「📋 业务分析」等），而不是通用标签
- 你可以从返回的 `contributions` 中读取各Agent内容

### 5. UI细节

- **合成模式header标签**：`🧠 多专家会诊 · 合成模式`
- **对比模式header标签**：`🧠 多专家会诊 · 对比模式`
- 切换开关用 `el-switch` 或 `el-radio-group`，放在header区域
- 视觉风格参考现有代码中的 `collaborate-section` 金色渐变卡片和 `parallel-section` 卡片

### 6. 注意事项
- 不要删现有代码，新旧并存，等测试通过再清理
- 确保切换对话、保存消息、离线模式等边缘情况正常
